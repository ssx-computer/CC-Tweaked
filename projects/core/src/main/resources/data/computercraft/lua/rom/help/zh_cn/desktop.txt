desktop 是一个图形化桌面：壁纸、图标、任务栏，以及可以移动、缩放和最小化的窗口。

输入 "desktop" 启动桌面。每个窗口里运行一个普通程序，所以可以同时打开多个程序。

用法：
"desktop" 启动桌面。
"desktop --install" 开机时自动启动桌面。
"desktop --uninstall" 取消开机自动启动。
"desktop --status" 查看当前壁纸和启动设置。
"desktop --wallpaper stars" 更换壁纸。可选壁纸有 stars（星空）、grid（网格）、ocean（深海）和 plain（纯色）。

使用桌面：
点击图标打开对应程序。“菜单”按钮会列出电脑和磁盘上的所有程序，在菜单里输入文字即可搜索。

拖动窗口的标题栏可以移动窗口。拖动窗口的右边缘、下边缘或右下角可以改变大小。双击标题栏可以最大化或还原窗口。
[-] 按钮最小化窗口，[O] 按钮最大化窗口，[x] 按钮关闭窗口。点击任务栏上的窗口按钮可以切换过去，再点一次会最小化。

在桌面空白处右键，可以打开终端、程序菜单、更换壁纸、设置开机自启或关闭桌面。在窗口上右键可以最小化、最大化或关闭它。

插入软盘后，桌面上会出现磁盘图标。打开它可以浏览磁盘里的文件。

键盘操作：
当没有窗口获得焦点时，用方向键选择图标，按回车打开。按 "m" 或 F1 打开程序菜单。菜单打开时，用方向键选择，
按回车确认，直接输入文字即可搜索。按退格清除搜索内容（搜索为空时会关闭菜单）。

要开机自动启动桌面，请运行 "desktop --install"。它会在 /startup/desktop.lua 创建启动文件，
不会改动已有的 /startup.lua。
