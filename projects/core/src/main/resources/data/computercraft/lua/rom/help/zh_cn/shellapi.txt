Shell API 中的函数:
shell.exit()
shell.dir()
shell.setDir( 路径 )
shell.path()
shell.setPath( 路径 )
shell.resolve( 本地路径 )
shell.resolveProgram( 名称 )
shell.aliases()
shell.setAlias( 别名, 命令 )
shell.clearAlias( 别名 )
shell.programs()
shell.run( 程序, 参数 )
shell.getRunningProgram()
shell.complete( 行 )
shell.completeProgram( 程序 )
shell.setCompletionFunction( 程序, 完成函数 )
shell.openTab( 程序, 参数 ) (需要高级计算机)
shell.switchTab( n ) (需要高级计算机)
