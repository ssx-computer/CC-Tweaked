turtle 是一个可用于所有乌龟机器人的 API，用于控制其移动和操作。

Turtle API 中的函数：

turtle.forward()
turtle.back()
turtle.up()
turtle.down()
turtle.turnLeft()
turtle.turnRight()
turtle.select( 槽位号 )
turtle.getSelectedSlot()
turtle.getItemCount( [槽位号] )
turtle.getItemSpace( [槽位号] )
turtle.getItemDetail( [槽位号] )
turtle.equipLeft()
turtle.equipRight()
turtle.dig( [工具方向] )
turtle.digUp( [工具方向] )
turtle.digDown( [工具方向] )
turtle.place()
turtle.placeUp()
turtle.placeDown()
turtle.attack( [工具方向] )
turtle.attackUp( [工具方向] )
turtle.attackDown( [工具方向] )
turtle.detect()
turtle.detectUp()
turtle.detectDown()
turtle.compare()
turtle.compareUp()
turtle.compareDown()
turtle.inspect()
turtle.inspectUp()
turtle.inspectDown()
turtle.compareTo( 槽位号 )
turtle.transferTo( 槽位号, [数量] )
turtle.drop( [数量] )
turtle.dropUp( [数量] )
turtle.dropDown( [数量] )
turtle.suck( [数量] )
turtle.suckUp( [数量] )
turtle.suckDown( [数量] )
turtle.getFuelLevel()
turtle.getFuelLimit()
turtle.refuel( [数量] )
turtle.craft( [数量] )（需要工艺乌龟）

Turtle API 触发的事件：
"turtle_inventory" 当物品栏中的任何物品发生变化时触发。使用比较操作来检查变化。
