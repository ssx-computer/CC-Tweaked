song 用于渲染使用 "SONG HTML" 标记语言编写的文档，这是一种在终端上显示带
样式文本的简易标记语言。传入一个文件即可运行：

    song example.song

文档就是普通文本，标记写在尖括号之间。所有标记都无需闭合，任何无法识别的
标记都会被静默忽略。如果 "<" 之后找不到 ">"，则剩余内容会作为普通文本输出。

标记可以带有一个参数，参数既可以写在尖括号内，例如 "<size 2>"，也可以紧跟在
尖括号之后，例如 "<size>2"。例如：

  <br>"Hello World"     开始新的一行，并在该行输出 "Hello World"。引号本身不会
                        显示；紧跟在 "<br>" 之后的引号字符串就是要在新一行写入
                        的文本内容。
  <size>8<size>         设置字号（此处设为 3，即最大值）。
  <colour>"red"         将文字颜色设为红色。
  <image>"路径"         在当前光标处绘制图片。

标记：

  <br>                 开始新的一行。"<br/>" 和 "<br />" 同样可用；标记后面
                       还可以紧跟一个引号字符串（见上文）。

  <size N>             将字号设为 N，其中 N 为 1、2 或 3。小于 1 的值按 1
                       处理，大于 3 的值按 3 处理。
  <size> 或 </size>    将字号重置为 1。

  <colour "名称">      设置文字颜色。
  <colour> 或 </colour>
                       将文字颜色重置为白色。"color" 和 "</color>" 同样
                       可以接受。

  <bg "名称">          设置背景颜色。
  <background "名称">  "background" 是 "bg" 的别名。

  <image "路径">       在当前光标处绘制图片。相对路径会相对于文档所在目录
                       解析。图片使用 paint 格式（.nfp），若路径以 ".nft"
                       结尾则使用 nft 格式。

  <!-- 注释 -->        被忽略。如果找不到 "-->"，则跳过文档剩余内容。

文本中可以使用反斜杠来转义下一个字符："\<" 输出 "<"，"\\" 输出 "\"，
"\x" 输出字符 x 本身。

颜色可以写为：
  * 一个数字，直接作为原始颜色值使用；
  * 一个十六进制值，例如 "#ff0000" 或 "ff0000"，会被匹配到 16 色调色板中
    最接近的颜色；
  * 一个颜色名称，例如 "red"、"lightBlue" 或 "grey"（不区分大小写）。

字号 2 和 3 会使用内置的 3x5 点阵字模放大绘制每个字符。只有字母 A-Z、
数字 0-9 和空格可以放大；小写字母会以大写形式显示。其他字符（例如中文字符）
则会以普通字号绘制。

示例：

    #!song
    <size 3><colour "yellow">SONG<colour>
    <bg "blue">
    <size 2>Hello, world!
    <bg>
    <size>
    <br>"Hello, world"
    一份用 <colour "lime">SONG HTML<colour> 绘制的大文档。
    <image "/rom/example.nfp">
