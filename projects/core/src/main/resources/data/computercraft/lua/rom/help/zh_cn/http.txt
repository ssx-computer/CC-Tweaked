HTTP API 中的函数：

http.checkURL( url )
http.checkURLAsync( url )
http.request( url, [postData], [headers] )
http.get( url, [headers] )
http.post( url, postData, [headers] )

HTTP API 可能在 ComputerCraft.cfg 中被禁用。

在调用 http.request() 后，经过一段时间会触发 "http_success" 或 "http_failure" 事件。
成功时，参数为请求的 URL 和一个文件句柄。
请求失败时，参数为 nil、一个错误消息，以及（可选的）一个文件句柄。
http.get() 和 http.post() 会阻塞直到此事件触发。
