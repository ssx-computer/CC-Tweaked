函数 os.pullEvent() 会暂停程序，直到系统事件发生。第一个返回值是事件名称，随后是任何相关参数。

可能发生的事件包括：
"char" - 当在键盘上输入文本时触发。参数为所输入的字符。
"key" - 当在键盘上按下按键时触发。参数为按键代码以及是否为重复按键。可将按键代码与 keys API 中的值进行比较，以确定按下的是哪个键。
"key_up" - 当键盘上的按键释放时触发。参数为数值的按键代码。可与 keys API 中的值进行比较，以确定释放的是哪个键。
"paste" - 当从键盘粘贴文本时触发。参数为粘贴的文本行。

仅在高级电脑上可用的事件：
"mouse_click" - 当用户点击鼠标时触发。参数为按钮、x坐标、y坐标。
"mouse_drag" - 当用户按住鼠标并移动时触发。参数为按钮、x坐标、y坐标。
"mouse_up" - 当用户释放鼠标按钮时触发。参数为按钮、x坐标、y坐标。
"mouse_scroll" - 当用户使用鼠标滚轮时触发。参数为方向、x坐标、y坐标。

其他 API 和外设会发出它们自己的事件。详见各自对应的帮助页面。
