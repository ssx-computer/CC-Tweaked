函数 os.pullEvent() 会暂停程序，直至发生系统事件。返回值第一个是事件名称，随后是各个参数。

可能发生的事件包括：
"char" 当在键盘上输入文本时触发。参数为所输入的字符。
"key" 当键盘上的按键被按下时触发。参数为按键码以及是否重复按键。将按键码与 keys API 中的值比较，可以确定是哪个按键被按下。
"key_up" 当键盘上的按键被释放时触发。参数为数字按键码。可与 keys API 中的值比较，确定是哪个按键被释放。
"paste" 当从键盘粘贴文本时触发。参数为所粘贴的文本行。

仅在高级电脑上可用的事件：
"mouse_click" 当用户点击鼠标时触发。参数为按钮、x坐标、y坐标。
"mouse_drag" 当用户按住鼠标移动时触发。参数为按钮、x坐标、y坐标。
"mouse_up" 当用户释放鼠标按钮时触发。参数为按钮、x坐标、y坐标。
"mouse_scroll" 当用户使用鼠标滚轮时触发。参数为方向、x坐标、y坐标。

其他 API 和外设会发出各自的事件。具体请参阅相应的帮助页面。
