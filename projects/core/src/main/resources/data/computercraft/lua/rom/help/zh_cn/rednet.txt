rednet API 提供了一种使用调制解调器实现简易计算机网络的模型。

rednet API 中的函数:
rednet.open( side )
rednet.close( [side] )
rednet.isOpen( [side] )
rednet.send( receiverID, message, [protocol] ) -- 发送到指定计算机
rednet.broadcast( message, [protocol] ) -- 广播到所有计算机
rednet.receive( [protocol], [timeout] ) -- 返回值: senderID, message, protocol
rednet.host( protocol, hostname )
rednet.unhost( protocol )
rednet.lookup( protocol, [hostname] ) -- 返回值: ID

rednet API 发出的事件:
"rednet_message" - 接收到消息时触发。参数为 senderID, message, protocol
输入 "help events" 了解事件系统。

rednet 并非使用调制解调器进行网络的唯一方式。直接使用外设 API 与调制解调器交互，并监听 "modem_message" 事件可以实现更底层的控制，但会失去 rednet 提供的高级网络功能。
