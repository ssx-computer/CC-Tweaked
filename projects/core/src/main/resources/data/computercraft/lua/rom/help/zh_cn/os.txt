操作系统 (OS) API 中的函数：

os.version()
os.getComputerID()
os.getComputerLabel()
os.setComputerLabel()
os.run( 环境, 程序路径, 参数 )
os.loadAPI( 路径 )
os.unloadAPI( 名称 )
os.pullEvent( [过滤器] )
os.queueEvent( 事件名, 参数 )
os.clock()
os.startTimer( 超时时间 )
os.cancelTimer( 标识符 )
os.sleep( 超时时间 )
os.time( [来源] )
os.day( [来源] )
os.epoch( [来源] )
os.setAlarm( 时间 )
os.cancelAlarm( 标识符 )
os.shutdown()
os.reboot()

os API 发送的事件：

"timer" - 当通过 os.startTimer() 设置的计时器超时时触发。参数为 os.startTimer() 返回的标识符。
"alarm" - 当通过 os.setAlarm() 设置的闹钟时间到达时触发。参数为 os.setAlarm() 返回的标识符。
输入 "help events" 了解事件系统的更多信息。
