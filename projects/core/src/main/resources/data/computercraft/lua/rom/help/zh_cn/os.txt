os（操作系统）API 中的函数：
os.version()
os.getComputerID()
os.getComputerLabel()
os.setComputerLabel()
os.run( 环境, 程序路径, 参数 )
os.loadAPI( 路径 )
os.unloadAPI( 名称 )
os.pullEvent( [过滤器] )
os.queueEvent( 事件, 参数 )
os.clock()
os.startTimer( 超时 )
os.cancelTimer( 令牌 )
os.sleep( 超时 )
os.time( [来源] )
os.day( [来源] )
os.epoch( [来源] )
os.setAlarm( 时间 )
os.cancelAlarm( 令牌 )
os.shutdown()
os.reboot()

os API 发送的事件：
"timer" 当由 os.startTimer() 启动的超时完成时。参数是 os.startTimer() 返回的令牌。
"alarm" 当到达 os.setAlarm() 设置的时间时。参数是 os.setAlarm() 返回的令牌。
输入 "help events" 了解事件系统。
