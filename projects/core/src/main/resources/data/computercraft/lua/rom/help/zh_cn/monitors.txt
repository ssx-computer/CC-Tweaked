显示器是一种可用于 CraftOS 的外设设备。输入 "help peripheral" 了解如何使用外设 API 连接外设。当显示器连接后，peripheral.getType() 将返回 "monitor"。可以使用 term.redirect() 将显示器包装后，将所有终端输出发送到显示器上。

显示器暴露的方法:
write( text )
blit( text, textColor, backgroundColor )
clear()
clearLine()
getCursorPos()
setCursorPos( x, y )
setCursorBlink( blink )
isColor()
setTextColor( color )
setBackgroundColor( color )
getTextColor()
getBackgroundColor()
getSize()
scroll( n )
setPaletteColor( color, r, g, b )
getPaletteColor( color )

显示器发出的事件:
"monitor_touch" - 当玩家触碰高级显示器时触发。参数为 name, x, y
"monitor_resize" - 当显示器大小改变时触发。参数为显示器的名称。
